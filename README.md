# Attitude
"Watch your attitude while you observe the horizon."

## What is it?
Attitude is a helper app which provides some quality-of-life improvements to Horizon OS, primarily intended for [PrivateQuest](https://xdaforums.com/t/app-5-0-private-quest-vr-headset-management-tool.4695491/) users.

The key benefit is that Attitude does not require root, allowing you to enjoy an annoyance-free experience without needing a vulnerable software version.

## Features
- WiFi auto-connection for networks that have no Internet access
    - Android disables auto-connection on these networks with the message "won't automatically connect"
- Improved notification drawer, including the ability for text input
    - *Yes, this means you can pair wireless debugging for apps like Shizuku and App Manager without needing workarounds or custom forks!*
- Automatically close annoying/non-functional pop-ups
    - The "Horizon Feed" that pops up on boot
    - The "Passthrough" dialog that prompts you to add a useless mirror
- Re-map some non-functional UI elements to more useful things
    - Profile button (click)
    - App drawer (press and hold)
- Shortcut to the real Android Settings app
    - Opens "App Info" page on newer OS versions as a workaround, but you can launch settings from there.

## Compatibility
Currently only tested on my Quest 2 running v83, but might work on newer/older versions.

I assume the re-mapping and pop-up closing don't work with the new "navigator" UI, but I have no way of testing that yet.

If this project picks up interest, I'll invest in a second Quest 2 HMD to test newer versions.
